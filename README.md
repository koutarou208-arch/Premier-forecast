# Global Financial Crisis Watch v3\n\n世界的な信用収縮を、現在値の高さだけでなく **異常度・悪化速度・市場横断の同時悪化** まで含めて監視する GitHub Pages ダッシュボードです。\n\n## v3 scoring\n\n自動取得できる市場指標は各チャネルを 0-100 点で評価します。\n\n- **Level 45%** — 絶対水準。既知のストレス閾値に対してどこまで上昇しているか。\n- **Deviation 30%** — 約5年（最大1260観測）の分布に対する percentile と robust Z-score。\n- **Velocity 25%** — 5観測・20観測の悪化幅を、過去の同期間変化と比較。\n- **Breadth overlay** — 複数市場が同時に45点以上へ悪化した時だけ 2.5-8点を追加。\n\nこれにより、水準はまだ低いが急速に悪化しているケースを v2 より早く拾えます。一方、単一市場だけが一時的に跳ねても高い伝播 Stage には進みません。\n\n## Data-quality rules\n\nv3 では取得失敗を **0点=安全** として扱いません。\n\n- 欠損チャネルは総合点の分母から除外\n- coverage_pct で有効データ比率を表示\n- 70%未満なら composite を provisional 扱い\n- Event 指標は confidence と as_of の経過日数で減衰\n\nEvent の鮮度減衰は、30日までは100%、31-60日85%、61-90日65%、91-180日40%、180日超15%です。\n\n## 9 risk channels\n\n| Channel | Weight | Source |\n| --- | ---: | --- |\n| US IG Corporate OAS | 12% | FRED BAMLC0A0CM |\n| US High Yield OAS | 18% | FRED BAMLH0A0HYM2 |\n| St. Louis Financial Stress | 10% | FRED STLFSI4 |\n| Treasury Vol / Liquidity | 10% | DGS10 RV20 + VIX; optional MOVE |\n| Italy-Bund 10Y spread | 10% | OECD/FRED monthly; optional daily override |\n| Energy shock | 10% | WTI + Henry Hub |\n| AI data-center financing | 10% | event evidence |\n| Private-credit liquidity | 12% | fund disclosures / event evidence |\n| Bank AI-credit inventory | 8% | syndication / lender evidence |\n\n## Transmission stages\n\n- Stage 0 — CALM: sector-to-system transmissionなし\n- Stage 1 — SECTOR REPRICING: AI / Private Creditに局所ストレス\n- Stage 2 — CREDIT TRANSMISSION: IG/HYを含む広範な企業信用へ伝播\n- Stage 3 — FUNDING STRESS: 信用悪化と資金調達・流動性ストレスが同時進行\n- Stage 4 — SYSTEMIC / FREEZE: Broad Credit と Funding がともに severe で、Breadth も高い\n\nStage 判定は headline score より厳しく設計しています。\n\n## Automatic data\n\nscripts/update_data.py が平日に FRED CSV を取得します。MOVE が未入力の場合、米10年金利の日次変化から20日実現ボラ（年率bps）を計算して代替します。これは MOVE そのものではありません。\n\nItaly-Bund は共通月の Italy 10Y - Germany 10Y を自動計算します。必要なら data/manual.json の europe_daily_spread_bps で日次値を上書きできます。\n\n## Event channels\n\n無料で安定した連続時系列がない AI data-center financing / Private-credit liquidity / Bank AI-credit inventory は data/manual.json で管理します。入力は0-3点で、v3が0-100へ変換し信頼度と鮮度を掛けます。\n\n## History\n\n更新ごとに data/latest.js、data/history.json、data/history.js を保存します。履歴は最大365観測です。\n\n## Refresh\n\nGitHub Actions は平日自動実行します。また v3エンジンや manual input を変更すると push でも自動再計算します。\n\n手動更新: **Actions -> Update crisis dashboard v3 -> Run workflow**\n\n## GitHub Pages\n\n**Settings -> Pages -> Deploy from a branch -> main / root**\n\n公開URL: https://koutarou208-arch.github.io/Premier-forecast/\n\n## Important\n\nこのスコアは金融危機が起きる確率ではありません。市場・信用・資金調達のストレス強度と伝播度を測る監視指数です。\n
